# UEFN Unreal Engine Scripting Library

A growing collection of Verse scripts and gameplay systems developed using Unreal Editor for Fortnite (UEFN)

This repository documents my ongoing work learning Verse and developing interactive gameplay systems, visual effects, and gameplay mechanics for Fortnite Creative and UEFN

## Current Focus

- Verse programming
- UEFN gameplay systems
- Device interaction
- Gameplay logic and state management
- VFX and SFX systems
- Interactive world elements
- UI and gameplay feedback

## Repository Structure

### Gameplay Systems

Reusable gameplay mechanics and systems implemented in Verse.

- **Tycoon Money Display** — Dynamic in-world currency display with configurable earnings, visual states, and a double-earnings mechanic.

### VFX & SFX

Scripts focused on visual and audio effects.

- **Random Steam VFX & SFX** — Randomized steam effect and audio system using asynchronous timing and editable UEFN devices.

## Current Projects

This repository is actively being expanded as I continue developing with UEFN and Verse. Future additions include more advanced gameplay systems, interactive mechanics, UI systems, and more.
